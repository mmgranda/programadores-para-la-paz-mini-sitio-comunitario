7. Comando usado para verificar la rama actual:

Respuesta: git branch

8. Comando que se usará desde la Clase 22 para traer cambios de main:

Respuesta: Para actualizar la rama personal con lo nuevo de main se utiliza: git merge main (habiendo actualizado main previamente con git pull).

9. Explica con tus palabras qué significa fast-forward:

Respuesta: Significa una actualización lineal y limpia en Git. Ocurre cuando la rama que queremos actualizar no tiene cambios nuevos guardados respecto a la rama de origen, por lo que Git solo tiene que mover el "puntero" hacia adelante hasta el último commit, integrando todo de forma directa y sin necesidad de crear un commit de fusión extra.

10. ¿Por qué no se debe trabajar directamente en main?

Respuesta: No se debe trabajar directamente en main para mantener el código de producción limpio, estable y libre de errores. Al trabajar en ramas individuales, cada estudiante experimenta y desarrolla de forma segura sin interferir con el proyecto principal ni con el trabajo de los demás compañeros.

11. Comando usado para revisar cambios al final:

Respuesta: git status

12. Comando usado para agregar cambios:

Respuesta: git add .

13. Comando usado para crear commit:

Respuesta: git commit -m "Clase 24 README IA login pedagogico"

14. Comando usado para publicar tu rama:

Respuesta: git push origin marien_segura
